# Resolved Technical Debt — Communication Frontend

This folder contains debt items that have been fully resolved — code merged, acceptance criteria met, and the fix verified in the browser or via automated tests.

## When Closing a Debt Item

1. Move the file from `Open/` into this folder.
2. Update the frontmatter: set `status: Resolved`, add `resolved-date` and `resolved-sprint`.
3. Update the originating sprint file to mark the item done.
4. Optionally link the resolving commit or PR in the file body.
