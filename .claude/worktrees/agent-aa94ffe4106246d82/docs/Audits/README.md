# Communication Frontend — Audits

This folder contains all formal audit documents for the Communication Frontend.

Audits are conducted:
- Before activating a new implementation phase
- After completing a sprint to assess readiness for the next phase
- When the Architecture Governance Agent requests a cross-service review

## Naming Convention

```
Audit-YYYY-MM-DD.md
```

If multiple audits occur on the same date, append a suffix: `Audit-2026-06-14-post-sprint.md`

## What an Audit Covers

- Sprint completion status
- Technical debt register review
- Readiness score (0–100)
- Blockers and risks
- Recommendations for next phase
