# Financial Policies

**Versión:** 1.0 | **Fecha:** 2026-07-06

Las Financial Policies son las reglas que aplican a **todos los Revenue Sources** del ERP. Una Invoice de Shift Work, de Services, de Products, o de Subscriptions comparte exactamente las mismas Financial Policies.
