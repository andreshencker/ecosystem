# Decision Records Index

This folder is the single canonical home for all platform decision records.

There are two series:

- **DEC-NNN** — Platform Decision Records. Detailed technical and architectural decisions with context, rationale, consequences, and implementation guidance.
- **ADR-NNN** — Architecture Decision Records. Higher-level architectural choices using the Context / Decision / Consequences format.
